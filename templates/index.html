AES Encryption

All files are encrypted with AES-256 before upload to ensure maximum security and privacy.

Searchable Encryption

Search through your encrypted files without revealing search terms or file contents to the server.

Steganographic Keys

Encryption keys are hidden in your profile picture using steganography, eliminating key transmission risks.

How It Works
Upload Process
  1. File is encrypted with AES-256
  2. Keywords are extracted and hashed
  3. Encrypted file uploaded to cloud storage
  4. Keys and indexes stored in profile picture
Search Process
  1. Search term is hashed locally
  2. Hashed term matched against encrypted index
  3. Matching files retrieved from cloud
  4. Files decrypted using keys from profile picture
